# 🏆 The Champions Club

Welcome to the repository for **The Champions Club** sports management system.

## Project Structure

- `/FrontEnd` - Contains the React 18 / Vite frontend application.
- *(More directories will be added as the backend is developed)*

### Getting Started

Navigate to the `FrontEnd` directory to find the main application and its documentation:

```bash
cd FrontEnd
npm install
npm run dev
```

For detailed information about the frontend tech stack, features, and folder structure, please read the [FrontEnd README](./FrontEnd/README.md) and the [STRUCTURE guide](./FrontEnd/STRUCTURE.md).
